# Quickstart: проверка ценового диапазона (spec 003)

```bash
npm test                      # все прежние тесты + tests/price-band.test.js
node scripts/ui-probe9.mjs    # сквозной сценарий в Chromium
```

## Ручная проверка

1. Загрузить Xray (и Cerebro/POE). Запомнить: выручку 1a, долю топ-бренда 1e, топ-5 1f, отзывы 1d, Adj. SV 1c.
2. В панели «Ценовой диапазон анализа» ввести «от 20», «до 30».
   - в шапке: «Анализ сужен до цен $20–30: N из M листингов, X % выручки ниши»;
   - 1b, 1d, 1e, 1f изменились и помечены «в диапазоне»; таблица конкурентов содержит только цены 20–30;
   - 1a: статус прежний, рядом справочно выручка диапазона и её доля;
   - 1c, трафик по ключам, сезонность, запуски — не изменились, помечены «вся ниша».
3. В секции «Ценовые сегменты» нажать «Premium» → границы подставились, выбранный сегмент подсвечен.
4. Ввести «от 80», «до 90» → предупреждение о малой выборке; «от 500» → «нет данных» у конкурентных показателей, дашборд не падает.
5. Ввести «от 30», «до 20» → поля подсвечены, расчёт по всей нише, сообщение о причине.
6. Цена товара 45 при диапазоне 20–30 → предупреждение о несоответствии.
7. «Сбросить» → значения из шага 1 до последней цифры.
8. F5 → диапазон на месте. Открыть анализ, созданный до фильтра → диапазон пуст, цифры прежние.
9. «Поделиться» (оба режима) → гость видит пометку о диапазоне в шапке.
10. Запустить AI → в обосновании упомянут диапазон; вердикт не мягче потолка правил.
