# Data Model: предлагаемая товарная линейка (spec 025)

Ничего не хранится и не мигрируется. Всё перечисленное считается при сборке результата из уже сохранённых данных анализа и живёт в `results.productLine`.

## Что берётся на вход (всё уже существует)

| Источник | Что даёт | Где |
|---|---|---|
| Выгрузка Xray | `parentAsin`, `isVariation`, `asinRevenue`, `price`, `brand` | `aggregates.xray.asins` |
| Схема характеристик | поля: `id`, `name`, `type`, `unit` | `config.schema.fields` |
| Таблица характеристик | значение поля по каждому ASIN | `config.table.rows[asin].values[fieldId].value` |
| Выбор конфигурации | значения полей своего товара | `config.priceChoice` |
| Статистика этапа 2 | доли выручки значений, признак премии | `results.config.whole.fields[]` |
| Ключевые слова | фразы, объём поиска, признак бренда | `aggregates.cerebro.keywords` |

## `results.productLine`

```
{
  status,            // "ok" | "no_variations" | "no_differences" | "no_repeating" | "no_stage2" | "no_xray"
  note,              // человеческая фраза для этого статуса
  families: {
    total,           // семей всего
    multi,           // семей из >=2 вариаций
    revenueShare,    // доля выручки у семей из >=2 вариаций
    medianSize       // медианный размер семьи
  },
  axes: [            // характеристики, прошедшие порог частоты; по убыванию частоты
    {
      id, name, unit,
      variesIn,      // в скольких семьях меняется
      ofFamilies,    // из скольких
      rate,          // variesIn / ofFamilies
      heavyValues,   // сколько значений держат >= порога выручки поля
      distinct,      // сколько разных значений всего
      chosen         // true у оси, по которой построена линейка
    }
  ],
  axisRejected: [    // оси, отклонённые правилом D1 — чтобы решение было видно, а не молча
    { name, rate, distinct, reason }   // reason: "no_repeating_values"
  ],
  items: [           // главный товар и варианты
    {
      role,          // "main" | "variant"
      axisId, axisName,
      value, label,  // значение оси у этого товара
      share,         // доля выручки поля у этого значения
      listings,      // сколько листингов его держат
      premium,       // за это значение платят больше
      price: {       // из priceByConfig для этого сочетания
        market, entry, ceiling,
        analogs,     // на скольких аналогах посчитано
        matchWords,  // "9 из 14"
        fallback     // true, если аналогов под сочетание не нашлось
      } | null,      // null — аналогов нет, цена НЕ выдумывается
      priceNote,     // почему цены нет, если её нет
      demand: {      // спрос из ключей
        sv,          // поисковый объём слова значения
        checked      // false — не искали (числовое значение или нет выгрузки ключей)
      },
      demandNote     // почему не искали
    }
  ],
  thresholds: { axisRate, valueShare, minHeavyValues },   // числа, по которым принято решение — называются человеку
  stage2: true
}
```

## Правила заполнения

- **`status`** — ровно один из шести, и каждый означает своё (решение D5):

| Статус | Когда | Что сказано человеку |
|---|---|---|
| `no_xray` | нет выгрузки Xray | блока нет, названа причина |
| `no_variations` | нет семей из ≥2 вариаций | «в нише не размечены вариации» — это про данные |
| `no_stage2` | есть вариации, но нет таблицы характеристик | показано, сколько вариаций; названо, что нужен этап 2 |
| `no_differences` | ни одно поле не меняется внутри семей | «товары внутри карточки по характеристикам не различаются» |
| `no_repeating` | оси есть, но ни одна не набрала двух весомых значений | «линейку здесь не строят: различия у каждой марки свои» |
| `ok` | ось выбрана | линейка предложена |

- **`axes`** содержит только поля с `rate >= thresholds.axisRate`. Поле, меняющееся в нуле семей, в список не попадает **никогда**: оно делит рынок, а не линейку (D2).
- **`axisRejected`** заполняется, когда ось прошла порог частоты, но не набрала двух весомых значений. Нужно, чтобы отказ был виден: иначе «Аромат, 95,8 % семей» просто исчезает из списка без объяснения.
- **`items[0].role === "main"`** всегда; главный товар берётся из `config.priceChoice`, по умолчанию доминанта.
- **`items[].price === null`** — аналогов под сочетание нет. Цена не выдумывается, `priceNote` называет причину.
- **`demand.checked === false`** — объём не искали. Причины: значение числовое или размерное (сопоставление со словом бессмысленно), либо выгрузки ключей нет. `demandNote` называет, какая именно.
- **`demand.sv === null` при `checked === true`** — искали, не нашли. Это не ноль спроса, и текст обязан различать «не искали», «не нашли» и «ноль».
- **`thresholds`** отдаются наружу намеренно: человек видит, по каким числам принято решение, не открывая код.

## Что НЕ попадает в снимок

`results.productLine` удаляется целиком функцией `stripProductLine` — и при создании публичной ссылки, и при сборке автономного HTML. Проверяется содержимым снимка (D7).
