# Feature Specification: Amazon как продавец в нише — правило вердикта

**Feature Branch**: `012-amazon-seller-rule` · **Created**: 2026-09-23 · **Status**: Implemented (см. tasks.md → «Выпуск»)

## Проблема

Если в нише продаёт сам Amazon (Seller / Fulfillment = Amazon), конкурировать с ним почти невозможно: цена, доставка, Buy Box. Сейчас приложение лишь отмечает это (пункт 1e «НЕ OK», минус в scorecard, строка в чеклисте), а вердикт остаётся мягким — менеджер может пропустить главный стоп-фактор. Нужен однозначный No-Go, но с выбором: смотреть на всю нишу или только на свой ценовой диапазон (Amazon за $90 не мешает продавать за $25), и с возможностью не блокировать, а учитывать как часть общей картины.

## User Scenarios & Testing

### User Story 1 — Однозначный No-Go (Priority: P1)

1. **Given** в Xray есть листинг, у которого продавец или отгрузка — Amazon, **When** анализ считается с порогом «Amazon как продавец = однозначно No-Go», **Then** потолок вердикта — No-Go, решающий гейт — «Amazon в нише», в причинах — число таких листингов и их доля выручки; AI-вердикт не может быть мягче.
2. **Given** менеджер вручную указал в чеклисте «Amazon продаёт сам: да / нет», **Then** ручной ответ важнее авто-определения по Xray.

### User Story 2 — Область проверки (Priority: P1)

1. **Given** порог «область = мой ценовой диапазон» и задан диапазон, **When** листинги Amazon вне диапазона, **Then** блокировки нет; **When** внутри — No-Go.
2. **Given** область = диапазон, но диапазон не задан, **Then** проверяется вся ниша (с пометкой).

### User Story 3 — Учитывать в общей картине (Priority: P2)

1. **Given** порог «режим = учитывать в общей картине», **Then** поведение прежнее: 1e «НЕ OK», −2 балла оси конкуренции, строка чеклиста, факт в AI; вердикт по остальным гейтам.

## Requirements

- **FR-001**: Определение — по каждому листингу Xray (Seller или Fulfillment равны Amazon / Amazon.com), а не по флагу всей выгрузки; для диапазона считаются только листинги коридора.
- **FR-002**: Пороги (вкладка «Пороги», группа «Amazon как продавец»): режим `block` (по умолчанию) | `consider`; область `niche` (по умолчанию) | `band`. Сохраняются с анализом и в личных наборах порогов (spec 011).
- **FR-003**: Результат виден в шапке (вердикт и решающий гейт), в «Конкурентной карте» (чип «Amazon продаёт сам · N листингов · X % выручки») и в чеклисте; попадает в AI-пейлоад, публичную ссылку и HTML.
- **FR-004**: Контрольные отпечатки прежних расчётов не меняются (вердикт уже исключён из отпечатка).

## Success Criteria

- **SC-001**: Ниша с Amazon при режиме «однозначно» → No-Go без участия AI и независимо от экономики.
- **SC-002**: Смена режима или области в «Порогах» меняет вердикт мгновенно, без перезагрузки файлов.
