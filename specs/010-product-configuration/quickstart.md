# Quickstart: этап 2 — конфигурация продукта (spec 010)

## Локально без ключей и кредитов

```
npm run dev            # MOCK_AI=1: Scrapfly и AI подменяются (страницы строятся из тайтлов Xray)
```

1. Загрузить Xray (и по желанию POE/Cerebro), дождаться дашборда.
2. Секция «Конфигурация продукта (этап 2)» → «1 · Предложить схему полей» → поправить в диалоге → «2 · Извлечь характеристики».
3. Смотреть диаграммы, переключать «вся ниша / мой диапазон», править клетки в таблице.
4. Секция «ТЗ производителю» → «3 · Составить ТЗ» → править → «⬇ Скачать DOCX».

## С реальным Scrapfly

`SCRAPFLY_API_KEY=…` в окружении сервера (на Railway — переменная сервиса; локально — из `.railway-secrets.env`, не коммитить). Проверка: `GET /api/health` → `scrapfly: true`.

Ориентир стоимости: 26–31 кредит на страницу, 100 ASIN ≈ 3 000 кредитов; страницы кэшируются в анализе на 30 дней. Схема строится по 40 листингам (порог `config.topForSchema`) — эти страницы потом переиспользуются извлечением, лишних кредитов нет.
