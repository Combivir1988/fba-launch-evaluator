# Контракт: данные раздела «Статистика»

Один запрос на открытие раздела. Отдельной ручки под список ниш нет: при 200 анализах весь список — 0,33 МБ, и второй круговой рейс стоил бы дороже, чем экономил (D1).

## `GET /api/stats`

**Доступ**: `requireUser` + `requirePasswordChanged` + право на раздел (`role === "admin" || stats_access`).

**Отказ без права**: `403 { "error": "no_stats_access", "message": "Раздел «Статистика» вам не открыт" }` — и **ни одной цифры в ответе** (FR-002, SC-001). Ни общего числа анализов, ни долей, ни названий ниш.

### Что в ответе обязано быть и чего в нём не должно быть

| Правило | Откуда |
|---|---|
| У каждого среза лежит **счёт**, а не процент; проценты считает браузер и всегда печатает рядом базу | FR-013 |
| `summary.n` — база для всех процентов; `freshness.empty` назван отдельно и в `n` не входит | FR-010 |
| В `rows` **нет автора анализа** — ни имени, ни id, ни счётчика по людям | FR-023, SC-001 |
| `rows[].id` нужен только чтобы открыть анализ из строки | FR-022 |
| `rows[].changed` / `was` — расхождение сохранённого и пересчитанного | FR-008 |
| Каждый срез пригоден для таблицы: ни один показатель не передаётся одним лишь цветом (`status` — подпись, а не единственный носитель смысла) | FR-021, SC-009 |

### Поведение по свежести

| Состояние | Ответ |
|---|---|
| Всё свежо | цифры из кэша, `stale: 0`, `recomputing: false` |
| Устарело 1…5 | досчитывается в запросе, ответ уже свежий |
| Устарело больше 5 | **прежние** цифры, `stale: N`, `recomputing: true`; догон в фоне (FR-028) |
| Догон упал | прежние цифры, `recomputing: false`, `stale > 0`, причина в `recomputeError` — видно, что пересчёт не прошёл, а не вечное «считаем» (FR-029). Упавший догон не перезапускается сразу: иначе битая база стоила бы попытки на каждое открытие, а человек видел бы вечное «идёт пересчёт» |
| Ни одного анализа с данными | `summary.n = 0`, срезы пустые; рисуется пустое состояние, а не нули (крайний случай спеки) |

Повторный запрос во время догона **не запускает второй пересчёт** (FR-030).

## Ошибки

| Код | Когда |
|---|---|
| `401` | нет сеанса |
| `403 no_stats_access` | сеанс есть, права нет — в том числе если право сняли минуту назад (FR-004, SC-008) |
| `503 storage` | база недоступна; общий обработчик приложения |

Пересчёт **никогда** не обращается к AI, Scrapfly или патентному поиску и не тратит кредиты: он считает по уже загруженным отчётам.

## Что добавилось при реализации

| Поле | Зачем |
|---|---|
| `freshness.failures[]` | `{ niche, error }` по каждому исключённому анализу, до десяти: SC-010 требует назвать не только число, но и причину |
| `freshness.recomputeError` | причина упавшего догона; без неё FR-029 неотличим от «ещё считаем» |
| `summary.blind[].kind` и `.na` | «нет данных у 65 из 65» и «зелёный у 1 из 65» — разные болезни и разные починки, поэтому различаются в самих данных, а не только в тексте |
