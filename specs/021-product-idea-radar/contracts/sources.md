# Contract: что запрашивается у площадок и что разбирается

Всё измерено 2026-11-12, по одному запросу на площадку. Разбор — чистые функции в `shared/idea-parse.js`, проверяемые на сохранённых образцах; в сеть тесты не ходят.

---

## Общие правила для всех трёх

1. **Один запрос на раздел в сутки.** Фон считается из той же выборки (D2), второго запроса не нужно.
2. **Прямой запрос первым, обход защиты запасным** (D7). Каким путём пришёл ответ — записывается в обход и видно человеку.
3. **Язык и регион задаются явно** (D8) — параметрами адреса и заголовком. Иначе площадка выбирает язык по адресу, с которого пришёл запрос.
4. **Ответ не на том языке — это отказ с причиной «язык не тот», а не пустота.** Разборщик обязан это различать: пустой разбор локализованного ответа выглядел бы как «ничего не нашлось».
5. **Элемент без опознавателя или без ссылки отбрасывается** и считается в «не разобрано».

## Мессенджер — превью публичного канала

**Запрос**: страница предпросмотра канала по его имени. Листание назад — параметром, но для суточного обхода не нужно: хватает одной страницы.

**Замер**: ответ **200**, 149 КБ, **20 постов**.

**Разбирается из каждого поста**:

| Величина | Вид в ответе | Примечание |
|---|---|---|
| опознаватель | номер сообщения | |
| ссылка | адрес поста | |
| текст | содержимое поста | хранится только у кандидатов |
| дата | **абсолютная**, ISO с зоной — `2026-08-03T07:19:56+00:00` | языка не зависит, разбирать безопасно |
| просмотры | **сокращённо** — `4.09M`, `7.75M`, `812K` | нужен разбор суффиксов |

**Чем это лучше остальных**: дата абсолютная. Ловушки с языком (D8) здесь нет.

**Ограничение, которое обязано быть сказано человеку** (FR-010, SC-012): поиска по площадке не существует. Радар видит только названные каналы — и ничего больше.

**Чего не бывает**: у личных имён предпросмотра нет, только у каналов. Закрытый канал недоступен. И то и другое — отказ с названной причиной.

---

## Видео — страница поиска по теме

**Запрос**: страница результатов поиска по теме раздела, **с явно заданным языком и регионом**.

**Замер**: ответ **200**, 1,66 МБ, данные страницы встроены в неё целиком, **20 роликов**.

**Разбирается из каждого ролика**:

| Величина | Вид в ответе | Примечание |
|---|---|---|
| опознаватель | идентификатор ролика | |
| название, канал | текст | |
| просмотры | **текстом** — `66,034 views` | точного числа в выдаче **нет**, только формат |
| возраст | **текстом, относительно** — `2y ago`, `3mo ago`, `1w ago`, `5d ago` | сокращённая форма |

**Замеренная ловушка**: без явного языка тот же запрос вернул **`2 lata temu`** и **`wyświetleń`** — язык выбрала площадка по адресу запроса. Разборщик под английский не нашёл бы ничего и записал бы «нет данных»: честно по форме, неверно по сути.

**Следствие для отбора**: возраст грубый (`2y` — это где-то от двух до трёх лет). Для свежих элементов, ради которых раздел и существует, точность достаточна (`5d`, `1w`, `3mo`); для старых — нет. Поэтому окно сопоставимости (`compareWindowDays`) отсекает старое и от грубости возраста защищает.

**Выдача упорядочена по совпадению с темой, а не по свежести.** Если окажется, что свежего в ней мало, запрос дополняется упорядочиванием по дате — это проверяется на первых живых сутках и записывается замером, а не угадывается сейчас.

## Краудфандинг — лента категории

**Запрос**: лента проектов категории в машиночитаемом виде — тот же адрес, который площадка вызывает сама; ни ключа, ни учётной записи не требуется.

**Замер**: прямой запрос отклонён — **403**, страница проверки браузера. Защита проверяет не учётные данные, а признаки клиента.

**Следствие**: эта площадка **обязательно** идёт через обход защиты, и она же самая дорогая. Она же самая ценная: показывает оплаченный спрос, а не внимание.

**Разбирается из каждого проекта** (состав полей подтверждается на первом успешном ответе и записывается в образец):

| Величина | Примечание |
|---|---|
| опознаватель, название, ссылка | |
| собрано | деньги |
| цель | нужна для доли от цели; ноль или отсутствие — второе условие невыполнимо |
| поддержавших | показывается человеку, в отбор не входит |
| дата запуска | для приведения к возрасту |
| валюта | суммы разных валют **не складываются и не сравниваются** без приведения; пока валюта одна на раздел, приведение не требуется — но смешение валют в одном разделе обязано быть замечено и названо |

**Что проверяется на первом живом ответе, а не предполагается сейчас**: точные имена полей, наличие даты запуска и поведение при смешении валют. До этого момента разборщик пишется по образцу, а не по памяти.
