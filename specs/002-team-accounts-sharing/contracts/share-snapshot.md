# Контракт снимка публичной ссылки

Источник истины — `shared/share-snapshot.js`, функция `buildSnapshot(analysis, {mode, preparedBy, snapshotAt, analysisVersion})`. Чистая, без ввода-вывода; вызывается сервером при создании и обновлении ссылки, тестируется на фикстурах.

## Формат

```json
{
  "type": "fba-launch-evaluator/share",
  "schemaVersion": 1,
  "mode": "full | no_economics",
  "preparedBy": "Имя пользователя",
  "snapshotAt": "2026-09-19T12:00:00.000Z",
  "analysisUpdatedAt": "…",
  "hidden": ["economics", "budget"],
  "analysis": { /* документ анализа версии 001, урезанный по правилам ниже */ }
}
```

`analysis` совместим с `FBARender.render(el, analysis, {static:true, hidden})` — публичная страница и кнопка «Скачать HTML» используют тот же рендерер и тот же сборщик автономного HTML, что и основное приложение. В скачанный HTML попадает ровно этот снимок.

## Правила для любого режима

- Удаляется `aggregates.cerebro.keywords` (сырые ключи: до 4 MB, рендереру не нужны); остаются сводные поля Cerebro, `aggregates.xray`, `aggregates.poe`, `aggregates.sqp` в объёме, который читает `render.js`.
- Удаляются служебные поля: `id` заменяется на случайный, `sources[*].fileName` сохраняется, внутренние идентификаторы пользователей не попадают; имя автора — только строкой `preparedBy`.
- `inputs.myAsins`, `inputs.myBrand` сохраняются (нужны разделам конкурентов); `thresholds` сохраняются.
- Блоки без данных (`ai: null`, `patents: null`) остаются `null` — рендерер в static-режиме показывает «не выполнялось» без кнопок запуска.
- Целевой размер: ≤ 250 KB raw, ≤ 60 KB gzip.

## Режим `no_economics` (FR-025, SC-006)

Удаляется, а не скрывается:

| Область | Действие |
|---|---|
| `inputs` | удаляются `cogs`, `cogsConfirmed`, `shippingPerUnit`, `referralPct`, `fbaFee`, `cvr`, `ppcShare`, `targetAcos`, `unitsPerDay`, `productionDays`, `shippingDays`, `receivingDays`, `adsReserve`, `budget`, `manualOverrides`; `price` и `cpc` остаются (рыночные величины) |
| `results.economics`, `results.budget` | удаляются целиком |
| `results.effective` | остаются `price`, `cpc`, источники; остальное удаляется |
| `results.gate0` / стоп-вопросы | удаляются пункты про бюджет и ROI; остаются выручка ниши и дифференциация |
| `results.challenger` | у критериев 2 и 6 остаётся статус и основание, комментарий заменяется на «экономика скрыта автором» |
| `results.scorecard` | балл оси экономики и итог остаются; расшифровка оси удаляется |
| `results.verdict` | вердикт и перечень причин остаются; из причин удаляются числовые значения экономики (остаётся формулировка «Gate 1 не пройден») |
| `ai` | `verdict`, `gates[*].status`, `differentiation`, `risks`, `nextSteps` — остаются после фильтра; `gates[*].reasoning` для Gate 1/2 и критериев 2, 6 — удаляется; `summary`, `recommendations`, `pricingPackComment`, остальные `reasoning` — фильтр по предложениям |
| `hidden` | `["economics","budget"]` + скрытые поля секций `hero`, `overview`, `quick`, `conclusion` |

**Фильтр предложений**: предложение удаляется, если содержит лексику `себестоим|cogs|марж|прибыл|roi|окупаем|бюджет|закуп|партии|acos|tacos|unit.?econom|юнит.?эконом|net\b` (без учёта регистра).

**Страховочная проверка значений**: из исходного анализа собираются числа: COGS, доставка/ед., FBA fee, прибыль/ед., маржа %, ROI %, бюджет, стоимость партий, резерв рекламы, Net по сетке CVR. Каждое ищется в сериализованном снимке в вариантах `12.5`, `12,5`, `12.50`, `13` (округление), `1250`, `1 250`, `1,250`, с `$` и `%`. Числа < 10 без дробной части не проверяются (слишком много ложных совпадений — их покрывает лексический фильтр). Поле, в котором найдено значение, удаляется целиком; факт записывается в `snapshot.redactions` (счётчик, без значений).

**Тесты**: (1) на фикстурах + mock-вердикте ни одно экономическое значение не встречается в JSON снимка и в собранном HTML; (2) полный режим отличается от исходного документа только отсутствием `cerebro.keywords` и служебных полей; (3) `render` в jsdom отрисовывает снимок обоих режимов без ошибок и без элементов управления (`button[data-action]`, `input`, `select` отсутствуют, кроме темы и «Скачать HTML»).

## Публичная страница

- Шапка: «FBA Launch Evaluator — отчёт по нише «…»», «Подготовил: <preparedBy> · снимок от <дата> · только чтение», для `no_economics` — пометка «закупочная экономика скрыта автором».
- Недоступная ссылка: единый экран «Ссылка недействительна: её не существует, она отозвана или истёк срок действия» — без названия ниши и автора.
- Без запросов к сторонним доменам; `<meta name="robots" content="noindex,nofollow">`, `<meta name="referrer" content="no-referrer">`.
