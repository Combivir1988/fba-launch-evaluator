# Tasks: распределение цен в нише (spec 024)

**Spec**: [spec.md](./spec.md) · **Plan**: [plan.md](./plan.md) · **Контракт**: [contracts/distribution.md](./contracts/distribution.md) · **Приёмка**: [quickstart.md](./quickstart.md)

Миграции нет. Нового хранения нет. Новых зависимостей нет. **Новых порогов в настройках нет.**

**Работа ДОБАВОЧНАЯ**: ни один существующий расчёт не меняется, вердикты не двигаются, контрольный отпечаток обязан остаться прежним на всех фикстурах.

**Порядок фаз следует плану, а не приоритетам историй.** US2 и US3 идут раньше US1, потому что MVP — это диаграмма: без неё работа не отвечает на главный вопрос «где в нише деньги». Объяснение цены конфигурации (US1) выпускается отдельно, чтобы его эффект мерился независимо.

## Dependencies

```
Phase 1 (T001–T002)   ← ДО любой правки в shared/
      ↓
Phase 2 (T003–T006)   ← T003 строго первым: отпечаток защищается ДО появления поля
      ↓
Phase 3 US2 (T007–T016)  ← MVP: нарезка и диаграмма
      ↓
Phase 4 US3 (T017–T020)  ← опирается на посчитанный «самый толстый коридор» из T009
      ↓
Phase 5 US1 (T021–T025)  ← независима от US2/US3, можно выпускать отдельно
      ↓
Phase 6 (T026–T030)
```

**Почему порядок не произволен:**

- **T003 строго раньше T012.** Поле появляется в результатах в T012; если оно не исключено из отпечатка заранее, прогон упадёт, и причину («задето лишнее» или «просто добавилось поле») придётся выяснять задним числом.
- **T009 строго раньше T017.** Порог «не разбирается» считается от доли самого толстого коридора — пока её не возвращает нарезка, считать нечего.
- **T012 отдельной задачей.** `compute()` собирает результат явным перечнем ключей; поле, которого там нет, молча не доедет, и **ни один тест не упадёт**. Это уже случалось дважды (спеки 020 и 022).
- **US1 независима.** Пояснения живут внутри `priceConfig`, который из отпечатка исключён целиком, — эта половина работы отпечаток не двигает вовсе и выпускается когда угодно.

## Implementation strategy

**MVP = Phases 1–4 (T001–T020).** После них в отчёте есть картина «где в нише деньги», и вырожденная диаграмма не выдаёт себя за неё.

**Phase 5 (US1)** — отдельный выпуск: пояснения к цене конфигурации не трогают отпечаток и измеряются независимо.

**Без Phase 6 не выпускается**: новая диаграмма без объяснения «что это» нарушает правило, по которому у каждого показателя есть пояснение.
