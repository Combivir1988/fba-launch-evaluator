# Контракт: правила совпадения имени бренда и смысловой близости (spec 023)

Формулировки — на уровне правил, а не кода. Контрольные значения обязаны проверяться тестом.

---

## 1. Нормализация

Имя бренда и фраза приводятся к одному виду: нижний регистр, апострофы удаляются, все остальные небуквенно-цифровые знаки заменяются пробелом, крайние пробелы снимаются.

| Вход | Нормализованное |
|---|---|
| `Ling's moment` | `lings moment` |
| `Melorca&Guilla` | `melorca guilla` |
| `MET` | `met` |
| `Amélie Home` | `amélie home` |

Нормализация **не меняется** этой работой.

---

## 2. Когда имя бренда считается найденным во фразе

Имя найдено, если выполнено **хотя бы одно**:

1. **Цепочкой слов.** Нормализованное имя целиком стоит во фразе как последовательность слов, ограниченная границами слов.
2. **Слитной записью.** То же имя с удалёнными пробелами стоит во фразе как **одно слово целиком**, ограниченное границами слов. Применимо только к именам из нескольких слов.

Подстрочное вхождение **не является** совпадением.

### Контрольные значения

| Фраза | Бренд | Найден? | Почему |
|---|---|---|---|
| `bike helmet` | `MET` | **нет** | внутри слова `helmet` — то, ради чего всё делается |
| `met helmet` | `MET` | да | отдельным словом |
| `casco met` | `MET` | да | отдельным словом |
| `helmets for adults` | `MET` | **нет** | внутри слова |
| `lings moment pillow` | `Ling's moment` | да | цепочкой слов |
| `lingsmoment pillow` | `Ling's moment` | да | слитной записью |
| `spiderman bike` | `Spider Man` | да | слитной записью |
| `protec helmet` | `Pro Tec` | да | слитной записью |
| `amazonbasics air conditioner` | `Amazon Basics` | да | слитной записью |
| `inside out storage` | `Out` | да | отдельным словом (ограничение принято осознанно, D2) |
| `geometry set` | `MET` | **нет** | внутри слова |

### Инвариант (проверяется на всех живых данных)

Новое правило **строго уже** прежнего: множество фраз, помеченных брендовыми, после изменения является подмножеством прежнего. Ни одна фраза не может получить признак брендовой, если раньше его не имела.

---

## 3. Защита ключа анализа

1. Однословное имя бренда, совпадающее со словом ключа анализа, для разметки **не используется**.
2. Фраза, равная ключу анализа, **никогда** не помечается брендовой.

Правило (1) уже действует для голов многословных имён и распространяется на полные имена. На живых данных сегодня не срабатывает (0 из 67) — это инвариант, а не исправление (research.md, D3).

---

## 4. Единое правило для лояльности к бренду

Расчёт доли поискового объёма с именем бренда использует **тот же** матчер (раздел 2). Собственной проверки не имеет.

Контрольное значение: бренд `Amélie Home`, фраз подстрокой 2, по правилу раздела 2 — 1; доля 8,5 % → 2,4 %, статус подпункта `warn → ok`. Вердикт при этом не меняется ни у одного анализа (замер двумя процессами).

---

## 5. Планка смысловой близости

Одна планка для любого формата выгрузки. Фраза близка к нише, если содержит **главное слово** ключа анализа — последний значимый токен после той же токенизации, по которой уже считаются группы ключей.

Если под планку попало меньше нужного числа фраз, планка смягчается **ступенями, в этом порядке**:

1. содержит главное слово ключа;
2. содержит не меньше половины слов ключа;
3. содержит хотя бы одно слово ключа.

Применённая ступень **называется человеку** рядом с отбором — так же, как уже называется смягчение отбора по силе конкурентов.

### Контрольные значения (ключ `Bike Helmet`, главное слово `helmet`)

| Фраза | Ступень 1 | Почему |
|---|---|---|
| `helmet` | проходит | главное слово |
| `kids helmet` | проходит | главное слово |
| `bike helmet adult men` | проходит | главное слово |
| `e bike helmet` | проходит | главное слово |
| `bike gear for men` | **не проходит** | главного слова нет |
| `capacete bike` | **не проходит** | главного слова нет |
| `mens blue bike` | **не проходит** | главного слова нет |
| `black bmx bike` | **не проходит** | главного слова нет |

Замер по этой нише: из 497 годных фраз ступень 1 оставляет **430**, отсекая ровно перечисленный мусор.

---

## 6. Правила отсутствия

| Случай | Поведение |
|---|---|
| Списка брендов нет | Брендовая разметка не делается; фразы остаются доступными |
| Имя короче 3 букв | Для разметки не используется |
| Имя в стоп-списке общих слов | Для разметки не используется |
| Ключ анализа пуст | Планка близости не применяется; отбор идёт по остальным условиям |
| У ключа одно слово | Главное слово — это оно же; ступени 1 и 3 совпадают |

---

## 7. Расхождение сохранённого кластера

Фраза считается **ошибочно отброшенной**, если одновременно:

1. по прежнему правилу (подстрока) она была брендовой;
2. по новому правилу (раздел 2) она не брендовая;
3. она проходит действующий отбор в кластер.

Число таких фраз показывается человеку. Действие «добавить» вносит их в кластер, **не трогая** остальной выбор. Открытие анализа само по себе кластер не меняет.
