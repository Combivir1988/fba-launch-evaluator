# Implementation Plan: несколько POE в одном анализе (spec 007)

**Spec**: [spec.md](spec.md) · **Date**: 2026-09-21 · **Migrations**: нет · **Новые зависимости**: нет · Сервер и API не меняются.

## Design decisions

- **D1 — расчёт по-прежнему видит один POE.** `aggregates.poe` — всегда один объект формы `parsePoe()`: одна ниша как есть или результат `mergePoe(parts)`. Остальное ядро о слиянии не знает; состав объединения лежит в `poe.merged`. Одна ниша возвращается тем же объектом — контрольные отпечатки не меняются (FR-006).
- **D2 — ниши по отдельности хранятся рядом** в `aggregates.poeParts`, только когда их больше одной (≈ 23 KB сжатых данных на нишу; предел хранения 3 MB). Старый анализ с одним POE становится первой нишей при добавлении второй — миграция не нужна. Предел — 8 ниш.
- **D3 — ключ ниши** = `meta.nicheId`, а без него — нормализованное название. Совпал ключ — ниша обновляется, иначе добавляется.
- **D4 — вес ниши** W = Σ кликов по её товарам за 360 дней; нет кликов — объём поиска ниши; нет и его — равные веса (названо в пометках). Доли кликов в POE внутри ниши в сумме дают 1, поэтому доля товара в общем рынке = Σ(доля в нише × W) ÷ ΣW — и сумма долей снова 1.
- **D5 — запросы.** Объём поиска — свойство запроса: у общего запроса берётся один раз (максимум), а из объёма ниши вычитается задвоение. Доля кликов — как у товаров. Конверсия поиска общего запроса — максимальная (не сумма): оценка конверсии клика не завышается.
- **D6 — сводные показатели.** Счётные (`*Count*`, `*Launched*`, `*Launches*`, кроме `avg*`) складываются; остальные — среднее, взвешенное по W; `top5/top20 Brands/Products ClickShare` пересчитываются по объединённому списку, `qoq/yoy` для них = null. Сводка ниши: объёмы и штуки складываются (штуки при общих товарах — верхняя оценка), цены и возвраты взвешиваются.
- **D7 — тренды** складываются только по неделям, общим для всех ниш: иначе короткая история одной ниши дала бы ложный провал сезонности (1g). Общих недель меньше 8 — берётся тренд самой крупной ниши с пометкой.
- **D8 — темы отзывов** сливаются по названию со взвешенной долей; Insights — из самой крупной ниши.
- **D9 — прозрачность.** Состав объединения виден в списке файлов (карточка на нишу с долей рынка и удалением), в чипе и пометке шапки, в «Особенностях данных POE» (`mergedPoeNotes`) и уходит в AI (`poe.mergedFrom`).
- **D10 — публичная ссылка и автономный HTML** получают объединённый POE без `poeParts`.
